# Aesthetic Design Pack v0.6

Version 0.6 expands GlyphLock from eight to fourteen original procedural wallpaper systems while preserving the semantic-morph rule: the event must be assembled from the wallpaper's own glyph topology.

## New systems

### Event Horizon
A gravitational lens with an accretion disk, photon rings, warped star positions, and bidirectional jets. Event text forms by locking the orbiting field into stable trajectories.

### Tesseract Engine
Nested projected cubes, dimension bridges, coordinate grids, and a central transform engine. It is the most architectural and precise system in the pack.

### Helix Array
A full-height double helix with sequencing rungs, telemetry rails, and a bright splice point. It provides a biological-computing visual language without becoming decorative DNA clip art.

### Interference Field
Three phase emitters generate overlapping wavefronts and analytically sampled bright loci. The final composition reads like a scientific instrument rather than a generic ripple effect.

### Cryo Vault
A hexagonal cold-storage chamber containing archive shelves, a central memory vial, and frost-like branches. This system is intentionally vertical and calm for lock-screen use.

### Dyson Relay
A segmented collector ring, stellar core, relay spokes, and lower receiver tower. It balances orbital motion with strong technical structure.

## Quality rules

- No static background plus notification card.
- Each system must remain desirable with events disabled.
- The event is compiled into targets consumed by the same source glyph topology.
- New generated masks are reproducible and not committed as opaque binaries.
- Theme identifiers must match across Android, the visual laboratory, and the procedural generator.
- Final reading state remains calm even when the ambient theme is visually dense.

## CI

`scripts/check_theme_catalog.py` rejects missing or mismatched theme identifiers and requires at least fourteen aligned systems.
