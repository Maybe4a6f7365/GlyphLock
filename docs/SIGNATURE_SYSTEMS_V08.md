# Signature visual systems — v0.8

## Chrono Loom

A precision chronograph woven from nested time rings, pendulum traces, escapement teeth, and vertical timing rails. Event metadata and the action hint travel along opposing arcs while the title and summary stabilize in the center of the mechanism.

- Motion: orbital
- Composition: dial
- Semantic idea: time becomes machinery

## Muon Chamber

A particle-detector volume with concentric chamber walls, radial sensor rays, collision tracks, and a luminous interaction point. Language resolves as a calibrated instrument reading within the detector.

- Motion: radial
- Composition: dial
- Semantic idea: an event is a measured collision

## Vector Shrine

A recursive perspective shrine constructed from technical frames, vector rails, stepped telemetry, and a central transform engine. Summary lines descend as a controlled cascade rather than a centered notification block.

- Motion: circuit
- Composition: cascade
- Semantic idea: information is routed through a computational monument

## Lagrange Garden

A living orbital diagram arranged around stable Lagrange nodes. Semantic lines occupy a constellation of slightly shifted anchors while the surrounding glyphs form node rings and connecting trajectories.

- Motion: bloom
- Composition: constellation
- Semantic idea: commitments find stable positions inside a dynamic system

## Transport rule

Every system uses the same invariant:

> Source glyphs retain identity, are matched to nearby semantic destinations, change character late in the motion, and return to their original coordinates when the event collapses.

No independent event card, text bitmap, or readability panel is permitted.
