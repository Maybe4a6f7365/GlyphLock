# Visual grammar

## Principle

The artwork is not a backdrop. It is the information material.

```text
TEXTURE → MOTION → STRUCTURE → LANGUAGE → TEXTURE
```

## Semantic motion

| Meaning | Transformation |
|---|---|
| Awake | A pulse reveals depth without presenting information yet |
| New | Source glyphs begin moving toward semantic targets |
| Important | Density and contrast converge around one focal system |
| Conflict | Competing flows compress or cross |
| Network | Orthogonal and wave traces route through the topology |
| Computation | Rings phase-lock around a core |
| Listening | A lower pressure wave deforms the existing event topology |
| Result | Event characters reorganise and stabilise |
| Dismissed | Every morph glyph returns toward its source coordinate |

Motion must describe a job, not merely provide activity: defense acquires, reactors ignite,
navigation routes, networks switch, biometrics decode, vaults unlock, clocks calibrate, sensors
scan, and analysis planes resolve measurements.

## Composition rules

- Keep the upper clock region quiet.
- Make both ambient and focused compositions full-screen; topology must reach side, lower, and corner zones.
- Use one dominant silhouette, topology, or instrument per theme.
- Every prominent rail, arc, node, or wave must belong to a recognizable AI subsystem operation.
- Prefer clean targeting brackets, armor plates, conduits, routes, detector walls, scan fans, and
  perspective decks over generic decorative rings or particle noise.
- Build detail from glyph density and contour, not giant terminal characters.
- Most ambient glyphs should remain spatially stable; movement communicates life, not chaos.
- Event language must be made from promoted source glyphs.
- Semantic strokes must be made from multiple retained ASCII symbols, never one literal character target per content character.
- A focused frame must read as ASCII macro-art up close and language at normal phone distance.
- Clear readability only around exact macro-glyph strokes.
- Do not clear or darken one global event rectangle.
- Do not derive decorative structure from the semantic bounds or surround copy with a partial border.
- Do not arrange title, prose, and action as a conventional text stack.
- Measure and fully wrap accepted event content; never clip or drop the final line.
- Supporting structure must preserve theme identity in the final state.
- Accent colour is sparse and semantic.
- Reading state reduces amplitude and speed.
- Private content must never become ambient texture in a future connected build.

## Motion grammars

- **Flow:** layered currents and shearing paths.
- **Orbital:** curved trajectories around a focal body.
- **Circuit:** orthogonal routing and stepped timing.
- **Radial:** contraction, expansion, and tangent motion.
- **Bloom:** petal-like opening and reassembly.
- **Wave:** phase displacement travelling across the field.
- **Fold:** multi-axis architectural folding.

## Semantic type grammar

- **Title:** the dominant macro-glyph formation; every letter stroke is a cluster of source ASCII symbols.
- **Signal lines:** at most two or three short facts, built from a denser compact macro grid or theme-aligned rails.
- **Metadata:** sparse source-symbol clusters attached to the artwork's existing axes, rings, or nodes.
- **Action cue:** a small structural change in the command zone, not a button label.
- **Close inspection:** source characters remain individually recognizable.
- **Normal distance:** words remain immediately readable without mentally decoding random particle noise.

## Rendering sequence

1. Generate a high-resolution procedural luminance mask.
2. Sample it into a dense static glyph field.
3. Select a bounded live subset for ambient motion.
4. Select persistent high-value source glyphs for semantic morphing.
5. Rank and shorten event language for the available semantic topology.
6. Compile language into macro-glyph stroke cells; never compile one literal character target per content character.
7. Compile theme-specific structural targets.
   Structural targets occupy screen space independently of the semantic bounds and express the
   theme's operational system intent.
8. Assign stroke cells and structure targets to nearby source glyphs while preserving source-symbol identity.
9. Deform remaining source glyphs according to the theme motion grammar.
10. Move only colliding filler glyphs around exact semantic strokes.
11. Settle into a calm, legible ASCII event topology.
    Semantic glyphs stop completely; system hardware receives only a brief purposeful motion tail.
12. Retarget that topology directly when a newer event arrives.
13. Reverse the same topology on dismissal.
