# Visual Grammar

## Principle

The artwork is not a backdrop. It is the information material.

```text
TEXTURE → MOTION → STRUCTURE → LANGUAGE → TEXTURE
```

## Semantic motion

| Meaning | Transformation |
|---|---|
| Awake | A radial pulse reveals depth without displaying information yet |
| New | Peripheral glyphs emerge and move inward |
| Important | Density and contrast converge around one focal region |
| Conflict | Competing flows intersect or compress |
| Network | Orthogonal traces route through the field |
| Computation | Rings phase-lock and breathe around a core |
| Listening | Lower glyph field responds in restrained amplitude bars |
| Reasoning | Ordered directional wave rather than an assistant orb |
| Result | Event state sharpens and stabilizes |
| Dismissed | Characters flow back toward their source coordinates |

## Composition rules

- Keep the upper clock region quiet.
- One dominant silhouette, topology, or technical instrument per scene.
- Build detail from density changes, not giant terminal characters.
- The resting field must move, but most glyphs remain spatially stable.
- Event copy opens a cavity inside the existing field.
- The cavity has no rectangle, drop shadow, or conventional card chrome.
- Accent color is sparse and semantic.
- Reading state reduces amplitude and speed.
- Motion must reveal structure, not obscure it.
- Private event content must never be repurposed as ambient texture in a future connected build.

## Current themes

### Sentinel — Flow

A frontal winged/human structure. Low-frequency current moves through the silhouette. Best for importance, protection, and situational awareness.

### Moth — Bloom

A symmetric organic structure with strong wing negative space. Six-lobed breathing emphasizes anticipation, collision, and change.

### Orbit — Orbital

An abstract circular/topographic form with counter-rotating glyph bands. Best for systems, deployments, and technical state.

### Neural Halo — Orbital

A synaptic graph with nested rings, node sparks, and slow counter-rotation. Best for model state, memory, and intelligence-related events.

### Cipher Cathedral — Circuit

A vertical cyber-reliquary built from data rails, cryptographic sigils, and architectural voids. Glyphs step along orthogonal traces. Best for security, certificates, identity, and infrastructure.

### Quantum Lattice — Radial

A perspective probability grid with interference shells and a bright measurement core. Best for simulation, research, uncertainty, and high-dimensional systems.

### Fusion Core — Radial

A reactor/tokamak instrument with concentric telemetry rings and pulsing confinement fields. Best for compute load, energy, thermals, and long-running work.

### Packet Bloom — Bloom

A radial network flower built from routes, nodes, and packet traces. Best for home-lab, network, latency, and connectivity events.

## Rendering strategy

Prototype 0 uses a hybrid Canvas renderer:

1. Decode a grayscale procedural mask.
2. Sample luminance into stable glyph positions.
3. Rasterize the dense ambient field once.
4. Select a bounded live subset for continuous movement.
5. Apply a theme-specific analytical motion function to that subset.
6. Lay out event typography into an irregular dark cavity.
7. Sample the title and summary into target points.
8. Move a bounded subset of glyphs from source to targets using the theme path grammar.
9. Crossfade the pre-rendered scene states around the live particles.

This intentionally avoids moving every glyph. Stable detail provides the high-quality wallpaper image; controlled motion supplies life and depth. A later GPU renderer can replace the implementation behind the same scene/state boundary.
