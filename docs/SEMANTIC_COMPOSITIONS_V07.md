# Semantic compositions — v0.7

## Why composition is separate from motion

Motion determines **how glyphs travel**. Composition determines **what the transformed wallpaper becomes**.

A theme therefore combines both:

```text
source mask
+ motion grammar
+ semantic composition grammar
= event-state identity
```

## Composition grammars

### Figure

Used by Sentinel and Moth. Language occupies the torso/central body while bilateral contour glyphs retain wings or organic symmetry. A centre spine prevents the final state from becoming disconnected text.

### Core

Used by Neural Halo, Fusion Core, and Packet Bloom. Title and summary phase-lock around a focal core while multiple structural rings survive the transformation.

### Orbital band

Used by Orbit, Event Horizon, and Dyson Relay. Two broken orbital bands frame the semantic centre. The gaps are intentional and prevent the structure from becoming a badge or circular card.

### Architecture

Used by Cipher Cathedral, Tesseract Engine, Cryo Vault, and Recursive Monolith. Language aligns to asymmetric vertical rails. Top and lower fragments create technical framing without enclosing the event inside a rectangle.

### Splice

Used by Helix Array. Two strands weave around the event lines and retain periodic centre rungs. The event appears to be a temporary decoded section of the helix.

### Field

Used by Quantum Lattice, Interference Field, and Spectral Observatory. Metadata and action occupy opposite sides; the title and summary stabilise inside several low-alpha wave rows.

## Text bands

Each rendered line creates an exact text band with a preferred displacement axis:

- architecture/splice: horizontal;
- field: vertical;
- figure/core/orbital: radial.

Only filler glyphs that collide with that line are displaced. No global event rectangle is cleared.

## Semantic role timing

Targets resolve in this order:

1. title;
2. summary;
3. metadata;
4. action hint;
5. decorative structure.

The source character remains visible until its target role enters the character-resolution window. The transition window is intentionally short so the morph reads as a character mutation rather than double-exposed text.

## New systems

### Spectral Observatory

A radio dish, receiver assembly, phase fronts, interferometer rays, and spectrum waterfall. It uses wave motion with the field composition.

### Recursive Monolith

An asymmetric stack of projected frames inside a sculptural monolith. It uses fold motion with the architecture composition.

## Quality rule

A final event screenshot should still reveal which theme generated it, even when the original ambient screenshot is hidden from the reviewer.
